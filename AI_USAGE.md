# AI tool usage

This project was developed with the AI coding assistant available in VS Code. It helped refine the project idea and implementation scope, scaffold the initial Python/React implementation, and draft tests and documentation. The assistant’s suggestions were checked against the task requirements and the code was validated with tests and a frontend build.

No AI model is used by the application to understand callers or decide what action to take. Those decisions are implemented in ordinary Python code.

Browser-provided speech recognition and speech synthesis are used only for voice input/output; recognized text is processed by the same Python rules as typed messages.

## Errors and corrections

The initial planning workflow could not open its requirements-review view, so implementation proceeded from the already agreed project scope. Token totals and downloadable usage logs were not exposed in the coding session interface. No counts or screenshots are invented here; add an export or screenshot from the actual tool usage panel before submission if the assessment requires that evidence.

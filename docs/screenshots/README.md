# Screenshots

Numbered PNGs `01`–`25` are wired into the root `README.md`.

They ship as **labeled placeholders** (dark cards with titles). Before a live review, replace any file with a real capture from your machine — keep the same filenames so README links keep working.

Quick capture tips:

1. Run `RUN_APP.bat`, walk the demo script in the README.
2. Snipping Tool / Win+Shift+S → save over the matching `NN-….png`.
3. Prefer 1280×720 or similar so the README doesn’t look stretched.
